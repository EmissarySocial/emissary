# Markdown Editor

This is the Markdown article type (`templateId: article-markdown`), the simple text-based way to write articles. It extends `article-base` ([stream-article-base](../stream-article-base)), inheriting the article schema, `default`/`published` states, draft workflow, widget layout, and all viewing/publishing actions, and can be created under streams whose templateRole is `top`, `home`, `folder`, or `article` (`containedBy`).

Per [template.hjson](template.hjson), it overrides only `create`, which seeds `content.format: "MARKDOWN"` with starter text (`# New Article`), and `editor`, which runs `edit-content` with `format: "MARKDOWN"` against [editor.html](editor.html) — an [EasyMDE](https://github.com/Ionaru/easy-markdown-editor) editor (currently loaded from the jsdelivr CDN, with a TODO to inline it) wrapping a `<textarea>` that posts the draft back to `/{StreamID}/editor` via htmx. It re-declares `tagPaths: ["data.tags"]` because tagPaths is deliberately not inherited through `extends`. Sibling variants [stream-article-editorjs](../stream-article-editorjs) and [stream-article-html](../stream-article-html) follow the identical override pattern with different editors.
