# Emissary Default

The default site theme: a clean, general-purpose look for content-focused websites, and the page chrome that every stream and user template renders inside. [theme.hjson](theme.hjson) declares `themeId: default` with `extends: ["global"]`, so this folder only supplies the visible skin — the shared design system (layout/typography CSS, javascript, hyperscript behaviors, htmx and icon resources) comes from [../theme-global/README.md](../theme-global/README.md) and is served under `/.themes/global/...`. The hjson also carries the admin-facing setup form (site name, icon, splash image), the `startupTasks` checklist shown to new domain owners, and the `startupStreams`/`startupGroups`/`defaultFolders` seed data used when a domain is first configured.

[page.html](page.html) is the outer skeleton: it renders [includes-head.html](includes-head.html) (meta tags, robots noindex, stylesheet links) and [includes-foot.html](includes-foot.html) (htmx, sse extension, hyperscript, bundled scripts), sets body-level htmx defaults (`hx-target="main"`, view transitions, push-url), and injects the active builder's output via `.GetContent`. [navigation.html](navigation.html) renders the nav bar: the Startup Checklist link while the domain is in the STARTUP state, the top-level `.Navigation` streams otherwise, then per-user items (Profile, Inbox, Conversations, Notifications with a live SSE-driven unread badge, and Server admin for owners) or Sign In/Join Now for anonymous visitors.

To extend the theme, edit these HTML files or the four CSS files in [stylesheet/](stylesheet/), which are concatenated by the `bundles.stylesheet` entry and served as `/.themes/default/stylesheet`. [content/](content/) holds the seed documents referenced by `startupStreams` (home.json for the EditorJS welcome page, markdown for the others), and [resources/startup/](resources/startup/) holds the images and splash page used during first-run setup. Field semantics (extends, bundles, startup data) are interpreted by `model/theme.go` and `service/theme.go`.
