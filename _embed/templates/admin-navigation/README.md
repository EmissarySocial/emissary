# Top Level

Admin console page for managing the site's top-level pages, served at `/admin/navigation` (the "Navigation" tab in the shared menubar). Uniquely among the admin templates, [template.hjson](template.hjson) declares `model: Stream`: `handler/admin.go` loads the Stream named by the URL's objectID and builds the page with `build.NewNavigation`, so the actions here operate on real top-level Stream records rather than Domain settings. All actions are owner-only.

The `index` action renders [index.html](index.html): summary cards that jump into admin-domain actions (`/admin/domain/themes` for the theme, `/admin/domain/defaults` for the start pages), an "Add a Page" button hitting the `add` action (`add-stream` at `location: "top"`), and a Sortable.js drag list of `.Navigation` streams that posts reordered IDs to the `sort` action against the schema's `rank` field. Each row links out to the stream's own `/{token}` and `/{token}/edit` pages for content editing, keeping this template purely about ordering and lifecycle; `delete` cascades to everything beneath the stream (the hjson also defines a `view` action, though no view.html exists in this folder). Extends `admin-common` for the shared menubar partial.
