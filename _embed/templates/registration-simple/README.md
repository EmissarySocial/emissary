# Free Registration

Open self-service signup flow (registrationId: `register-simple`) that collects a visitor's name, email address, username, and password, then confirms the account by email. It is defined by [registration.hjson](registration.hjson) and selected/configured per-domain in the admin console; the `form` block builds that admin UI (tabs for page content, confirmation message, inbox/outbox templates, an auto-join group, an optional secret, and up to four terms-of-service checkboxes), stored as the domain's RegistrationData.

The visitor flow is the standard `/register` pipeline: `view` renders [view.html](view.html) as a standalone full page with honeypot anti-bot fields and required terms checkboxes; `handler.PostRegister` validates the submission and emails a welcome link; `confirm` renders [confirm.html](confirm.html) with the configured markdown message; and the User is actually created when the emailed JWT link hits `GET /register/complete`. Unlike registration-invite-code, the secret here is not typed by the visitor — the `secret` action renders [secret.html](secret.html), a hidden input pre-filled from DomainData that the view includes in the form, so it acts as a bot-deterrent token rather than an invite gate. `allowedFields` limits which submitted values are copied onto the new User.
