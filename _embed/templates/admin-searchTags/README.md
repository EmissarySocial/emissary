# Tags

Admin console page for curating the searchable hashtags on the site, served at `/admin/tags` under the "Search > Tags" sub-menu. Note the naming mismatch: this folder is `admin-searchTags` but [template.hjson](template.hjson) declares `templateId: admin-tags`, and it is the templateId that `Template.LoadAdmin` matches against the URL. The model is `Tag`, so `handler/admin.go` loads the SearchTag named by the URL's objectID and builds the page with `build.NewSearchTag`; all actions are owner-only.

The `index` action renders [index.html](index.html), a filter form (name, group, status — the latter two fed by `.Groups` and `.States`) that refreshes the embedded `list` view; [list.html](list.html) shows up to 600 tags (`Top600.ByName`) with name, group, and status columns. The `add` and `edit` actions open modals with tabbed forms defined inline in the hjson covering the tag name, group, status (`searchTag-states` provider), rank, related hashtags, banner colors, and admin-only notes; `edit` additionally includes an image upload handled by an `upload-attachments` step (600x600, max 1) with its heading in [edit.html](edit.html). Two things to watch when extending: the `delete-image` action deletes the `iconId` field while the upload writes `imageId`, and [view.html](view.html) plus [status-widget.html](status-widget.html) are not referenced by any action in the hjson (view.html is user-management markup carried over from admin-users). Extends `admin-common` for the shared menubar partial.
