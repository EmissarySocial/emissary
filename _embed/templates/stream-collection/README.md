# Collection

A Collection (`templateId: collection`, `templateRole: collection`) is a stream that combines all of its children into a single page: [view.html](view.html) pulls in [content.html](content.html), which renders an optional sidebar of anchor links (controlled by the `data.showSidebar` schema property) next to a column of placeholder divs that lazy-load each child stream inline via htmx `hx-trigger="revealed"`. It can live under streams whose templateRole is `top`, `folder`, or `article` (`containedBy`), and it extends `base-widget-editor`, which supplies the `stylesheet` bundle, the LEFT/TOP/RIGHT/BOTTOM widget locations, and the single `default` state (this template defines no states of its own — the inheritance in `service/template.go` fills them in from the parent).

Defined in [template.hjson](template.hjson), the notable actions are `view`, `edit` ([edit.html](edit.html) drag-sorts children with SortableJS and posts the new order through the `sort` step), `add-child` (opens the add-stream picker for items to append), `widgets`/`widget` for the surrounding widget layout, plus modal `properties` (token, label, summary, sidebar toggle) and `sharing` (simple-sharing on the `viewer` role). [heading.html](heading.html) renders the editor menu bar and is used when the collection appears as a fragment. Unlike the article family there is no draft workflow — edits save directly to the live stream.
