# Children

This widget (widgetId `children`) displays a table-of-contents style list of the child streams organized beneath the current stream in the site map, with each row linking to the child page. It is the simple way to surface a folder's contents on the parent page itself.

[widget.hjson](widget.hjson) defines a three-field schema — `title` (string, shown as a heading when non-empty), `showIcon` (boolean, default true), and `showDescription` (boolean, default true) — edited through a vertical form with a text input and two toggles. [widget.html](widget.html) reads those settings via `.Widget.Data.GetString`/`GetBool`, then iterates `.Children.Slice` (the Stream builder's query for child stream summaries) rendering each child's `Icon` (via the `icon` template function), `Label`, and `Description` inside an `hx-boost="true"` anchor; the wrapper div sets `hx-target="main"`, `hx-swap="innerHTML"`, and `hx-push-url="true"` so clicks load the child page into the main region via htmx instead of a full page load. To change sorting or filtering of the list, note that `.Children` returns a QueryBuilder, so methods on it can be chained in the template before calling `.Slice`.
