# Group

Admin console page for managing permission Groups, served at `/admin/groups` under the "People > Groups" sub-menu. [template.hjson](template.hjson) declares `model: Group`, so `handler/admin.go` loads the Group named by the URL's objectID and builds the page with `build.NewGroup`; every action is owner-only.

The `index` action renders [index.html](index.html), a card with an "Add a Group" row that embeds the `list` action inline via `{{.View "list"}}`; [list.html](list.html) pages through groups 60 at a time (`Top60.ByLabel`) with an htmx `revealed` trigger for infinite scroll. The `add` and `edit` actions open modals sharing a tabbed form defined inline in the hjson (label, token, icon via the `group-icons` provider, and an admin-only description); `edit` first renders the heading in [edit.html](edit.html), which exposes the GroupID and a "Manage Users" link filtering `/admin/users?groupId=...`. Add, edit, and delete all finish with `startup-save-task` to tick the "/admin/groups" item on the startup checklist, and delete warns that members are removed from the group but not deleted. Extends `admin-common` for the shared menubar and startup-banner partials.
