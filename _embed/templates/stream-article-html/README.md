# HTML Code

This is the raw-HTML article type (`templateId: article-html`, labeled "Experts only"), a thin variant of the article family. It extends `article-base` ([stream-article-base](../stream-article-base)), inheriting the shared schema, states, draft workflow, widget layout, and all viewing/publishing actions, and can be created under streams whose templateRole is `top`, `home`, `folder`, or `article` (`containedBy`).

Per [template.hjson](template.hjson), it overrides only `create`, which seeds `content.format: "HTML"` with starter markup (`<h1>New Article</h1>`), and `editor`, which runs `edit-content` with `format: "HTML"` against [editor.html](editor.html) — a plain `<textarea>` that autosaves the draft on blur via htmx and hooks the base template's `saveDraft(promote)` convention for the Promote button. It re-declares `tagPaths: ["data.tags"]` because tagPaths is deliberately not inherited through `extends`. Sibling variants [stream-article-editorjs](../stream-article-editorjs) and [stream-article-markdown](../stream-article-markdown) follow the identical override pattern with different editors.
