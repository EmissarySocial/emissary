# Scrollspy

This widget (widgetId `scrollspy`) adds an intra-page navigation menu to a stream: it scans the page's main content for headings, builds a linked outline of them, and highlights the entry for the section currently in view as the reader scrolls. It is entirely client-side, so it works on any stream whose content renders headings.

[widget.hjson](widget.hjson) declares no schema or form, but does declare a `hyperscript` bundle (content-type `text/hyperscript`), which the widget service assembles from the [hyperscript/](hyperscript/) folder and serves at `/.widgets/scrollspy/hyperscript` — the URL loaded by the `<script type="text/hyperscript" src=...>` tag in [widget.html](widget.html). The rest of widget.html is inline CSS for the sticky `#scrollspy` container plus the empty div itself; [hyperscript/scrollspy._hs](hyperscript/scrollspy._hs) does the work on `init` by finding `h1`–`h4` elements inside the first `.e-content` node, assigning each a random id when it lacks one, appending `.scrollspy-item` anchors indented by heading level (`scrollspy_indent`), and then re-running the `scrollspy()` position check on window scroll (debounced 20ms) and on menu clicks, which uses `measure` to find the first heading in the viewport and `take .selected` to move the highlight. To support more heading levels or a different content container, edit the selectors in the `_hs` file and the `.level-*` styles in widget.html.
