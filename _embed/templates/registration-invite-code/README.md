# Invite Code Registration

Self-service signup flow (registrationId: `register-invite-code`) for invite-only servers: visitors may create an account only if they enter the secret invitation code the domain owner configured. Like all registration templates it is defined by [registration.hjson](registration.hjson) rather than a template.hjson, and it is selected and configured per-domain in the admin console; the `form` block defines that admin config UI (tabs for page content, the invite code, confirmation message, inbox/outbox templates, an auto-join group, and up to four terms-of-service checkboxes), whose values are stored as the domain's RegistrationData.

The visitor flow runs through the `/register` routes in `server.go`. The `view` action renders [view.html](view.html) as a standalone full page (`as-full-page: true`) with the configured heading, markdown description, honeypot anti-bot fields, required terms checkboxes, and the invite-code input; `handler.PostRegister` validates the submission (including the secret against RegistrationData) and emails a welcome link, after which the `confirm` action renders [confirm.html](confirm.html), the configured markdown confirmation message. The account itself is only created when the visitor clicks the emailed JWT link (`GET /register/complete` → `service.Registration.Register`), and `allowedFields` limits which submitted fields (displayName, emailAddress, username, password) are copied onto the new User.
