# Visual Editor

This is the block-based WYSIWYG article type (`templateId: article-editorjs`), the beginner-friendly way to write articles in Emissary. It extends `article-base` ([stream-article-base](../stream-article-base)), inheriting the article schema, `default`/`published` states, draft workflow, widgets, sharing, and view rendering, and can be created under streams whose templateRole is `top`, `home`, `folder`, or `article` (`containedBy`).

Per [template.hjson](template.hjson), it overrides only two actions: `create` seeds the stream with `content.format: "EDITORJS"` and empty raw content (`"{}"`) before forwarding to the edit screen, and `editor` runs `edit-content` with `format: "EDITORJS"` against its own [editor.html](editor.html), which mounts an [Editor.js](https://editorjs.io) instance on the draft content and saves by POSTing the editor's JSON back to `/{StreamID}/editor` (optionally following with `promote-draft`). It re-declares `tagPaths: ["data.tags"]` because tagPaths is deliberately not inherited through `extends` (see the comment in `model/template.go`). To build another editor variant, copy this pattern: extend `article-base`, set the content format in `create`, and supply an `editor.html`.
