# Folder

A Folder (`templateId: folder`, `templateRole: folder`) is the basic container stream in Emissary: it holds other web pages and lists them in one of three layouts (`data.format`: TABLE, CARDS, or COLUMNS, with an optional `data.showImages` toggle). Folders can sit at the site's top level or inside other folders (`containedBy: ["top", "folder"]`), and children are sorted by label ascending (`childSortType`/`childSortOrder`). It has `default` and `published` states with `viewer`/`editor` roles, though `create` immediately runs `save-and-publish` with `outbox: true`, so new folders go live right away.

Everything is defined in [template.hjson](template.hjson) plus a single [view.html](view.html), which emits RSS/Atom/JSON feed discovery links (backed by the `feed` action's `view-feed` step), an editor menu bar, and the chosen child layout. There is no custom edit page: the `edit` action opens an hjson-defined form in a modal (`as-modal` over the `view` background), including a conditional rule that shows `data.showImages` only for non-FOLDER formats. Other actions are `add-child` (the add-stream picker), `sort` (drag-order children), `sharing` (simple-sharing on the `viewer` role), and `delete`, which unpublishes with `outbox: true` before removing the folder and its contents.
