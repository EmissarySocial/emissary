# Widget Editor (Base Template)

Shared base template (category: Base, model: Stream) that provides the drag-and-drop widget-placement editor used by any Stream template that supports widgets. Templates absorb it by listing `base-widget-editor` in their `extends` array; embedded consumers are `stream-article-base` (and through it the article variants) and `stream-collection`.

[template.hjson](template.hjson) declares the default `widget-locations` (LEFT, TOP, RIGHT, BOTTOM) and two asset bundles — [stylesheet/editor.css](stylesheet/editor.css) and [hyperscript/widgetEditor._hs](hyperscript/widgetEditor._hs) — which are served at `/.templates/base-widget-editor/stylesheet` and `/.templates/base-widget-editor/hyperscript`. It defines no actions of its own: it only contributes the HTML definitions [widgets-list.html](widgets-list.html) (the full editor, which loads Sortable.js plus the bundles and posts widget placements to `/{streamId}/widgets`) and [widget.html](widget.html) (a single draggable widget chip with an optional Edit button). Extending templates wire these up by defining their own `widgets` action (using the `sort-widgets` step) and `widget` action (using the `edit-widget` step), as `stream-article-base` and `stream-collection` do, and may override the `widget-locations` list to restrict where widgets can be placed.
